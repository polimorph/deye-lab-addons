# deye-lab-addons

Add-on-uri private pentru laboratorul Deye Intelligence.

| Add-on | Rol |
|---|---|
| `emhass_perfect_world` | Rulează același EMHASS MPC (PPC MaxControl) ca producția, dar pe PV și consum perfecte. Scenariul `EMHASS_PPC_PERFECT_PV_LOAD` din scoreboard. |

Instalare: Settings → Apps → App store → ⋮ → Repositories → `https://github.com/polimorph/deye-lab-addons`.
